# 精细化去水印 POC 结果

日期：2026-11-24　样本：8 个真实视频、720p 截帧（另含 3 帧时间冗余用于求稳定 mask）

## 做法

1. **笔画级 mask**（不再整块矩形）
   - `bilibili` 文字标：用检测锚点定位后，直接按模板描出精确笔画（模板来自 `bilibili_anchor_detector.dart`）；
   - UP 主昵称：在锚点行带内，用形态学高/低帽提取亮笔画与暗投影，多帧投票保留"固定出现在屏幕上的像素"；
   - 只保留文字行内、尺寸像笔画的连通域，最后外扩 1~2 px 覆盖抗锯齿边缘。
2. **只替换 mask 内像素**：用归一化卷积（normalized convolution）从最近的已知像素平滑外推，mask 之外的 61% 区域原样保留。
3. 对比对象：当前线上 shader 的 `piliplus_fill`（整块矩形四边采样 + 双线性混合）。

## 结果

| 样本 | 场景 | 结果 |
| --- | --- | --- |
| sample1_topright_dark | 暗背景 | 文字完全消失，几乎无痕 |
| sample2_topleft_bright | 亮背景低对比 | 文字消失，留下轻微柔化 |
| sample3_topright_white | 白窗帘/天空 | 文字消失，4× 放大仅有极淡柔和残影 |
| sample4_bottomleft_texture | 碎石路面 | 文字消失，留下一块模糊色块（无法恢复纹理细节） |
| sample5_bottomright_edge | 文字跨明暗边界 | 文字消失，但边界处有柔化残影 |

- mask 平均只占原矩形面积的 **39%**（干净背景样本约 30%），其余像素完全不动；
- 整块填充在同一位置会糊掉整条 283×91 区域并产生条纹/色带，笔画级修复把破坏面缩小到文字本身；
- 试过的其它方案：方向射线填充会产生放射状条纹；alpha 逆混合（`(I−α·text)/(1−α)`）因 α 估计不稳定，会把文字"半透明化"地留下，已放弃。

## 结论与限制

- 值不值得做：**值得**。在平滑/暗背景（最常见的角标场景）效果接近无痕，明显优于整块填充；在强纹理或强边界上仍有可见柔化块，但破坏面积小得多。
- 落地方式：mask 在检测阶段用带水印的帧算一次，打包成小位图常量写进 GLSL；运行时每个像素只做 9 次采样，开销可以忽略。
- 前提：检测阶段必须拿到**带水印的帧**。目前 API 帧（首帧 / 雪碧图）多数是干净源，因此该方案只对"接口帧带水印"的视频生效；运行时截屏采样已按需求移除，不会再加回。
